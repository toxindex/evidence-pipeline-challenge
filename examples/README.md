# Starter examples

The Go and Python examples perform the same small operation: fetch recent drug
recalls from openFDA, validate a source identifier, normalize a few fields, and
write NDJSON plus retrieval provenance.

- [`go-openfda`](go-openfda)
- [`python-openfda`](python-openfda)

Both use only their language's standard library and include unit tests. They
are deliberately incomplete; candidates may extend either or start over.
